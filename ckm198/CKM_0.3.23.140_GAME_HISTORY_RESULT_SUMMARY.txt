CKM Quiz Pro 0.3.23.140-dev.172-GAME-HISTORY-RESULT-SUMMARY

- В подробной истории игры добавлена визуальная итоговая карточка.
- Для завершённой игры показываются победитель или ничья, места команд и финальный счёт.
- Для игры с одной командой показывается результат команды без ложного объявления победителя.
- Для незавершённых игр показываются только текущие позиции; победитель заранее не объявляется.
- В итоговой карточке отображаются длительность, число команд и количество сыгранных вопросов/испытаний.
- Для «Переговори другого» метрика испытаний строится по сохранённой серверной сессии.
- Исправлен источник итогового счёта в истории: используется фактический team.score, потому что общий finish-path не заполняет final_score во всех форматах.
- То же исправление применяется к списку истории и CSV-экспорту, чтобы завершённые игры не показывали ложный ноль.
