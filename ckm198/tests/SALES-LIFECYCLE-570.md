# Regression suite .570

Один запуск из корня `ckm198`:

```sh
node tests/run-sales-lifecycle-570.mjs
```

Требуются Node.js, PHP 8.3 CLI с `mbstring` и `pdo_sqlite`. Другой путь к PHP задаётся через `--php /path/to/php` или `PHP_BINARY`. В облачной среде без установленного PHP использовался настоящий PHP 8.3.33 в официальном WordPress Playground WASM:

```sh
node tests/run-sales-lifecycle-570.mjs --php /workspace/ckm-dev-tools/php-cli.mjs
```

WASM-инструменты находятся вне плагина. ZIP не содержит Node-зависимости или тестовую базу. Для такой среды установите `@php-wasm/node` и `@php-wasm/universal` вне рабочей папки и используйте CLI-обёртку, передающую фактический exit code PHP. Проверка синтаксиса через `php-parser` не выполняет эти тесты и не заменяет их.

Suite запускает изолированные PHP-фикстуры. Production-классы выполняют решения, мутации, создание кейсов, назначения и SQL-запросы; фикстуры заменяют границы WordPress, внешних API и хранилища. Decision-алгоритмы в тестах не копируются. Для SQL используется SQLite в памяти. Ошибка, ненулевой exit code или отсутствие итогового счётчика дают ненулевой статус общего запуска. Исходящие HTTP, сокеты и shell-вызовы в PHP отключены.

Проверяются адаптивный фокус и уровень, порог 75 и transfer, исключение recertification из прогрессии, индивидуальный exam и командное соревнование, повторное назначение, приватность реального диалога, повторяющиеся методические сигналы, изменение стандарта, сопоставимость baseline, эффект и управленческое решение, идемпотентность, устаревшая редакция, права и tenant isolation.

Live smoke-test выполняется отдельно после установки, без автоматического обращения к production. Ни WordPress UI, ни реальные игры, платежи или LLM в этом suite не используются.
