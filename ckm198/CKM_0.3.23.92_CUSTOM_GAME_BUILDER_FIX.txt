0.3.23.92-dev.124-CUSTOM-GAME-BUILDER-FIX

Кнопки «Создать свою игру» открывают view=builder без ID готовой игры.
Старая ссылка #ckm-custom-game перенаправляется в конструктор.
При отсутствии права конструктора показывается сообщение о доступе.
После входа сохраняется переход в конструктор с учётом площадки.
Проверки прав, форматов, сохранения и режима просмотра сохранены.

Установка: загрузить ZIP через Плагины → Добавить плагин → Загрузить плагин,
заменить установленную версию. Затем обновить страницу кабинета Ctrl+F5.

Проверено: синтаксический разбор четырёх изменённых PHP-файлов;
пять сценариев обработки старых ссылок. На живом WordPress не проверено.
