CKM Quiz Pro 0.3.23.229-dev.261 — READY GAME ADMIN TEST LAUNCH

- В админском «Каталоге готовых игр» добавлен реальный «Тестовый запуск».
- Тест создаёт комнату через настоящий runtime с test_mode=1.
- Оплата и доступ не расходуются; тест не считается коммерческой сессией.
- Тестовая сессия остаётся в админской истории с пометкой тест.
- Счётчик коммерческих сессий готовой игры исключает test_mode=1; отдельно отображается число тестов.
- Кнопка тестового запуска доступна из таблицы каталога, формы редактирования, предпросмотра и preflight.
- Старый общий экран «Тестовый запуск» также переведён с test_mode=0 на test_mode=1.
