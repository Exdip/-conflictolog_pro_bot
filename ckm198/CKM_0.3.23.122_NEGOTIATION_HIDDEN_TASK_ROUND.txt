Добавлено:
- Переход из завершённого раунда «Удержи цель» во второй раунд после подтверждения трёх команд.
- Раунд «Скрытая задача»: три выступления, каждая команда один раз активная.
- 30 секунд подготовки и 90 секунд общего текстового разговора.
- Только активная команда видит три закрытые задачи; две другие команды видят только общую роль собеседника.
- Все три команды могут отправлять реплики во втором раунде.
- После завершения разговора скрытые задачи раскрываются.
- ИИ-арбитр: 0/100 за каждую из трёх задач, максимум 300; положительная оценка требует точной цитаты активной команды.
- Одна реплика может подтвердить несколько разных задач; каждая задача начисляется только один раз.
- Накопительный счёт после двух раундов.
- Совместимость с уже созданными сессиями .109-.121: старые сообщения считаются раундом 1.

Скрытые задачи:
Команда A: день недели; благодарность за конкретное предложение; альтернатива.
Команда B: время встречи; уточняющий вопрос; собственная помощь.
Команда C: место встречи; причина предпочтения; итог договорённости.
