CKM Quiz Pro 0.3.23.246-dev.278-GAME-TITLE-RENAMES

Переименование пользовательских названий деловых игр во всех runtime-поверхностях:
- «Ваш выбор» → «Управленческая игра \"Ваш выбор\"»
- «Продажи» → «Эффективный продажник»
- «Деловые переговоры» → «Мастер переговоров»
- «Экспресс-раунд» → «Переговорный раунд»
- «Переговори меня» → «Переговори другого»

Технические format/product/runtime keys не изменены для обратной совместимости.
Обновлены PHP/JS, встроенные каталоги, подписи конструктора, партнёрские списки, сценарные варианты, тесты и документация пакета.
