0.3.23.187-dev.219-JEOPARDY-VOICE-TIMER-GATE

Интеллектуальный батл: Voice -> Timer Gate.

- Обычный вопрос в режиме ИИ-ведущего открывается без server deadline.
- Базовый таймер и кнопка ответа/зуммер недоступны, пока голос ведущего не закончен.
- После ckmqp:voice-playback-ended сервер атомарно запускает question_deadline_at.
- «Секретная передача» также не принимает ответ до окончания озвучивания вопроса.
- Финальный вопрос в режиме ИИ-ведущего открывается без таймера и без поля ответа.
- После окончания озвучивания финального вопроса стартует отдельный авторитетный финальный таймер.
- AI autopilot не может раскрыть финал, пока финальный таймер ещё ожидает окончания голоса.
- При невозможности опубликовать голосовую реплику применяется безопасный fallback: таймер запускается сразу.
- Ручной ведущий сохраняет прежний немедленный запуск таймеров.
- Сохранены STT single-owner fix 185 и защита AI -> manual 180.
