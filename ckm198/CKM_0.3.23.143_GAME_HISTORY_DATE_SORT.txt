CKM Quiz Pro 0.3.23.143-dev.175-GAME-HISTORY-DATE-SORT

- История игр: фильтр по диапазону дат «с / по».
- История игр: сортировка сначала новые / сначала старые / по названию / по формату.
- Диапазон дат и сортировка сохраняются при пагинации, открытии карточки, возврате назад и удалении тестового запуска.
- CSV-экспорт списка использует тот же диапазон дат и тот же порядок сортировки.
- Если даты введены в обратном порядке, диапазон автоматически нормализуется.
