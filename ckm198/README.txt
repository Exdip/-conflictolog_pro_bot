0.3.14.1 — CKM room UI parity routes

- Один запуск теперь явно выдаёт три роли: комнаты команд, комнату ведущего и публичное табло.

- В истории запусков добавлена прямая кнопка «Ведущий» рядом с «Табло».
- Техническая админка также всегда показывает ссылку ведущего.

- Shared Quiz Core, схема БД, ключи форматов и игровая механика не изменялись.
- Это безопасный route/role этап. Полный перенос визуального слоя основного сайта остаётся отдельным этапом 0.3.14.2.


0.3.13 — main-site room flow

Исправлено по образцу основной платформы centr-razvitia-uma.ru:
- игровые комнаты снова имеют отдельные URL /ckm/quiz-room.html, /ckm/quiz-host.html и /ckm/quiz-scoreboard.html;
- комнаты перехватываются до WordPress canonical/frontdoor redirect, поэтому не зависят от главной страницы или slug WP Page;
- в «Интеллектуальном батле» самостоятельный выбор ячейки командой разрешён только при ИИ-ведущем, как на основной платформе;
- при ведущем-человеке ячейку выбирает ведущий в своей панели;
- убран standalone-only барьер «сначала подключить все команды» перед выбором ячейки;
- выбор ячейки выполняется той же последовательностью Core, что на основном сайте: select_cell -> special check -> open_next_question;
- после действия сервер возвращает авторитетное состояние игры.

0.3.12 — «Интеллектуальный батл»

Добавлено:
- третий формат в технической админке и frontend-конструкторе: «Интеллектуальный батл» (technical key: jeopardy, runtime: jeopardy_v1);
- поле 4 категории × 3 номинала (100 / 200 / 300) с редактируемыми категориями и вопросами;
- команда с правом выбора открывает свободную ячейку;
- обычный вопрос: команды соревнуются кнопкой «ОТВЕЧАЕМ!», первой нажавшей команде даётся отдельное короткое время на текстовый ответ;
- неверный ответ не уменьшает счёт, ответившая команда блокируется на текущий вопрос, остальные могут нажать кнопку;
- «Секретная передача»: выбравшая команда передаёт вопрос одной другой команде, которая отвечает без кнопки;
- необязательный финал без ставок: все команды отвечают скрыто, верный ответ даёт фиксированные +500;
- ИИ-ведущий: автоматический ход/локальная проверка по эталону и допустимым вариантам;
- Ведущий (с микрофоном/без микрофона): ручной выбор ячеек, принятие/отклонение ответов, управление финалом;
- голос человека-ведущего продолжает работать через gateway.video-training.ru;
- публичное табло показывает игровое поле, текущий вопрос и счёт;
- CKM Game Package v1 теперь разрешает запуск jeopardy-пакетов;
- демо «Демо: Интеллектуальный батл» содержит 12 основных ячеек + финал;
- Smoke Test проверяет jeopardy_v1, standalone adapter и демо.

ВАЖНО ПРО AI:
В standalone DEV-сборке защищённый CKM Cloud ещё не подключён. «ИИ-ведущий» означает автоматическое ведение игры, а текстовые ответы локально проверяются только по эталону/допустимым вариантам. Семантический AI-арбитраж, МИНД/СМКМ и секретные промпты должны оставаться в CKM Cloud.

0.3.9 — «Битва знатоков» alongside «Классический квиз»

Что добавлено:
- второй доступный формат: «Битва знатоков» (technical key: chgk);
- общий Quiz Core 87.2 используется без форка и без изменения fingerprint;
- создание и редактирование «Битвы знатоков» в технической админке;
- тот же формат в frontend-конструкторе организатора, если конструктор разрешён тарифом;
- одна команда Знатоков против Игры, один общий командный экран и один окончательный ответ;
- 60–300 секунд обсуждения, серверный дедлайн;
- первая финальная отправка команды блокирует её ответ;
- запуск после готовности единственной команды;
- локальная фиксация результата в общем ScoreEvent ledger после закрытия вопроса;
- автопереход к следующему вопросу и завершение игры;
- публичное табло и локальная история используют общий игровой движок;
- демонстрационная игра «Демо: Битва знатоков» на 11 вопросов;
- CKM Game Package v1 теперь может запускать classic_quiz и chgk;
- Smoke Test отдельно проверяет runtime и демо обоих форматов.

ВАЖНО ПРО АРБИТРАЖ:
CKM Cloud в этой DEV-сборке ещё не подключён. Поэтому текстовые ответы «Битвы знатоков»
локально сравниваются с эталонным ответом и явно указанными допустимыми вариантами
(нормализация регистра и пробелов). Семантический AI-арбитраж, МИНД/СМКМ и секретные
методики должны выполняться только через CKM Cloud и в клиентский ZIP не включаются.

Инфраструктура по умолчанию:
- основной сайт: https://centr-razvitia-uma.ru
- CKM Cloud API: https://api.centr-razvitia-uma.ru/v1
- управляемые клиентские сайты: *.ckkm.ru
- realtime/voice: https://gateway.video-training.ru

Frontend:
- главная ckkm.ru — входная дверь платформы;
- /ckm-login/ — вход организатора;
- /ckm-organizer/ — кабинет организатора;
- конструктор виден только при явном разрешении для учётной записи;
- /wp-admin/ для роли CKM Organizer недоступен.

Типографика:
- Ubuntu — основной интерфейс;
- Caveat — заголовки и акценты, как на основном сайте ЦКМ.

Безопасность:
Закрытый Ed25519-ключ в плагин НЕ включён. Production private key должен храниться
только в CKM Cloud; клиентскому плагину нужен только public key.
