# Управленческая игра "Ваш выбор" — исправление создания игры

Исправлена синхронизация раундов общего Game Format Layer.

Для `solution_price` основной раунд сохраняется как `case`, что соответствует контракту формата (`case`, `final_case`). Ранее общий синхронизатор принудительно менял его на `questions`, после чего создание комнаты завершалось ошибкой `round_type_not_allowed`.

Также форма создания игры теперь сохраняет выбранный шаблон после ошибки вместо визуального возврата к первому пункту списка.
