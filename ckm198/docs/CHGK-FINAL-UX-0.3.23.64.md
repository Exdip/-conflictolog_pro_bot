# CHGK final UX — 0.3.23.64

- CHGK built-in registry matches the actual single-team duel.
- Victory mode: `first_to_six`; target score: 6; no tie-break/ranking branch.
- Tiebreak state is disabled when `tieBreakMode=disabled`.
- Participant, host and scoreboard shells show a dedicated final result card.
- Early human termination is labelled as early termination and does not invent a winner.
- No database schema migration is required.
