# CKM Quiz Pro 0.3.23.54 — CHGK one-team mode

Изменения:
- «Битва знатоков» допускает от 1 до 10 команд.
- Новые CHGK-шаблоны сохраняются с `min_teams=1`.
- Существующие CHGK-шаблоны автоматически нормализуются до `min_teams=1`.
- В админской и организаторской форме для CHGK значение по умолчанию — 1 команда.
- Другие интеллектуальные форматы не меняются; их минимумы остаются прежними.
