# 0.3.23.44 — Interface Editor

Добавлен раздел WordPress-админки:

`Игровая платформа → Редактор интерфейса`

## Что редактируется

- Главная страница `ckkm.ru`:
  - надзаголовок;
  - заголовок;
  - описание;
  - кнопки входа/кабинета;
  - вторая кнопка и URL;
  - карточка «Организаторам».

- Страница выбора игр и оплаты:
  - витрина площадки;
  - заголовки блоков «Оплаченные игры» и «Игры для оплаты»;
  - тексты кнопок оплаты/открытия/добавления;
  - сообщения об уже оплаченных играх и пустом списке.

- Кабинет организатора:
  - обзор;
  - библиотека «Мои игры»;
  - создание нового запуска.

- Комната ведущего / участника / табло:
  - подписи верхней панели;
  - подписи кнопок ведущего;
  - подсказка перед стартом с голосом;
  - заголовки ответов, счёта и табло.

## Хранение

Настройки сохраняются в `wp_options` как `ckm_quiz_pro_interface_settings`.
Обновления плагина не перезаписывают сохранённые тексты.

## Ограничения

Редактор в этом этапе управляет текстами, кнопками и видимостью основной карточки главной страницы. Перетаскивание блоков и глубокая визуальная верстка оставлены для следующего этапа.
