# CKM Quiz Pro 0.3.23.38 — Переговорный поединок

Один формат `negotiation_duel` с тремя режимами:

- `sales` — Эффективный продажник;
- `business` — Мастер переговоров;
- `express` — Переговорный раунд (60 секунд).

## Реализовано

- новый формат в registry/runtime;
- товар `negotiation_duel_v1` и алиасы доступа;
- выбор режима в админке и frontend-кабинете организатора;
- текстовые переговорные реплики вместо вариантов ответа;
- отдельные профили критериев для трёх режимов;
- три демо-шаблона по 5 ходов;
- ИИ-арбитраж через AI Puffer REST с локальным rubric fallback;
- начисление баллов и сохранение комментария арбитра;
- авто-закрытие хода после ответов всех активных команд;
- интерфейс участника: «Отправить реплику», режим, таймер на реплику и карточка ИИ-разбора;
- формат поддерживает 1–10 команд и использует общую историю CKM.

## Принцип

Это не три отдельных игры: движок, комнаты, токены, история и арбитраж общие. Меняются сценарий, время и критерии оценки.
