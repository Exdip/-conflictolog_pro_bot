CKM Quiz Pro 0.3.23.12 — кабинет после оплаты

Установить архив с заменой предыдущего CKM Quiz Pro.
До оплаты /ckm-organizer/ показывает только заголовок оплаты и три карточки.
Выбор игры открывает цену, срок доступа и кнопку перехода к оплате.
Левая панель, запуск игры, статистика и обзор до оплаты не выводятся.

Условие полного кабинета: у текущего пользователя есть действующая запись
в существующей таблице game_access для одного из трёх продаваемых форматов:
status=active, expires_at позже серверного UTC-времени.
Оплата другого пользователя, истёкший доступ и роль администратора не открывают
панель. В режиме просмотра организатора учитывается доступ этого организатора.
После подтверждения оплаты существующим платёжным модулем и записи доступа
панель появится при следующем открытии/обновлении кабинета.

Проверка выполняется перед обработчиками POST и выбором раздела: прямые ссылки
на new-game/library/builder/results без оплаты показывают экран покупки;
POST создания игры или сохранения конструктора через кабинет не исполняется.
Это ограничение кабинета; API игрового движка в данной итерации не изменяется.

Как проверить на WordPress:
1. Пользователь без оплаты: три карточки, без боковой панели и «Запустить игру».
2. Открыть ?view=new-game и ?view=builder: остаётся экран покупки.
3. Выбрать игру: цена и кнопка оплаты, без боковой панели.
4. После подтверждённой оплаты обновить кабинет: появляется панель.
5. Пользователь с истёкшим доступом снова видит экран покупки.

Платёжный модуль должен реализовывать ckm_create_game_payment_url и сохранять
подтверждённый доступ. Эта сборка не имитирует оплату.
Требования исходного плагина: PHP 8.3+, WordPress 6.9+.
На живом WordPress сборка не устанавливалась; PHP runtime локально отсутствует.
