# 0.3.23.43 — Host voice before Start

- «Включить Сергея», `Cartesia · Сергей` и «Диагностика голоса» показываются только в комнате ведущего.
- Комнаты участников и публичное табло подключаются к голосовому WebSocket автоматически как слушатели, без управляющих элементов.
- В комнате ведущего Сергей после каждой загрузки страницы выключен до явного нажатия «Включить Сергея».
- Для ИИ-ведущего старт игры блокируется, пока Gateway не подтвердит голосовое соединение.
- После подтверждения голоса ведущий нажимает «Запустить игру». Только после этого открывается первый вопрос.
- После ручного старта ИИ-ведущий продолжает игру автоматически.
- Начальный автозапуск через подключение команд отключён для последовательных форматов и ЧГК; у «Интеллектуального батла» выбор ячейки заблокирован до старта ведущим.
