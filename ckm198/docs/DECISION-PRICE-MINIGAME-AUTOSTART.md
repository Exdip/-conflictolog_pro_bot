# Управленческая игра "Ваш выбор" — mini-game autostart

- `solution_price` uses the existing sequential AI-host autopilot.
- The demo template `demo-solution-price` defaults to one team in the organizer launch form.
- After the only team joins, the first stage opens automatically.
- Full `solution_price` games can still use 1–10 teams; when more than one team is selected, start waits until every active team has joined, matching the existing safe AI-host behavior.
- No separate engine or room type is introduced.
