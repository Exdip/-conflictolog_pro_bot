# 0.3.23.36 — Paid game catalog state

- Оплаченная игра больше не предлагается повторно к покупке на той же tenant-площадке.
- На витрине и в разделе оплаты оплаченные форматы показываются отдельно с кнопкой «Открыть игру».
- Неоплаченные форматы находятся в разделе «Игры для оплаты».
- Уже оплаченные позиции автоматически удаляются из нового checkout-корзины.
- AJAX создания платежа дополнительно блокирует повторную оплату уже активного формата.
