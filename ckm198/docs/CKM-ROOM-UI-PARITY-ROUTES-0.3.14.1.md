# CKM Quiz Pro 0.3.14.1 — CKM ROOM UI PARITY ROUTES

Цель этапа — сделать роли игры явными и стабильно доступными без изменения общего Quiz Core.

Маршруты:
- `/ckm/quiz-room.html` — участник/команда;
- `/ckm/quiz-host.html` — ведущий;
- `/ckm/quiz-scoreboard.html` — публичное табло.

После создания игры кабинет организатора показывает все командные ссылки, отдельную ссылку ведущего и ссылку табло. Комната ведущего доступна и при AI-host для наблюдения; сервер не разрешает ручные управляющие команды в AI-host режиме.

Shared Core и схема БД не изменены.
