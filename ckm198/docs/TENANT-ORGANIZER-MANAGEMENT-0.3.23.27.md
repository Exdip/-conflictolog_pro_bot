# Tenant organizer management — 0.3.23.27

Добавлен frontend-раздел `Кабинет организатора → Площадки и организаторы`.

- владелец площадки может назначить отдельного организатора для каждого tenant/поддомена;
- существующего пользователя можно назначить по логину или email;
- новый email создаёт учётную запись WordPress с ролью организатора и отправкой стандартной ссылки для задания пароля;
- текущие пароли никогда не читаются, не показываются и не сохраняются в таблицах CKM;
- доступны действия «Отправить ссылку для входа» и «Сбросить пароль»;
- смена организатора меняет только membership tenant; owner остаётся владельцем;
- раздел доступен до покупки игр, чтобы администрирование площадки не зависело от entitlement.
