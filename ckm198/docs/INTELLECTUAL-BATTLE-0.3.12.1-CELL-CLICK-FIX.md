# CKM Quiz Pro 0.3.12.1 — Intellectual Battle cell click fix

Исправлено расхождение standalone UI и runtime:

- право выбора ячейки принадлежит команде с `selectorTeamId` независимо от режима ведущего;
- при `host_mode=human` команда-селектор может нажать 100/200/300, после чего обычный вопрос открывается сразу;
- ведущий-человек по-прежнему может выбрать ячейку сам из панели ведущего;
- для AI-host сохранено требование подключения всех команд до первого выбора;
- для human-host это требование снято, как и в других ручных форматах.

Shared Quiz Core не изменён.
