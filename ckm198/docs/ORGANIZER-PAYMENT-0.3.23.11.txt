0.3.23.11 — Оплата внутри кабинета организатора

Обновить CKM Quiz Pro этим архивом с заменой установленной версии.
На главной удалена кнопка «Техническое администрирование».
Открыть /ckm-organizer/: карточки трёх игр расположены в обзоре кабинета.
Выбрать → /ckm-organizer/?view=payment&game=... → Перейти к оплате.
Также добавлен пункт «Оплата игр». Использованы существующие стили кабинета.
Для гостей сохранён вход организатора. Права доступа не изменены.

Для реального платежа нужен внешний обработчик ckm_create_game_payment_url.
Если он не подключён, кнопка выводит понятную ошибку. Доступ по клику не выдаётся.
Сборка включает изменения 0.3.23.10, повторно ставить её не нужно.
Старый CKM Payment Page Hotfix 0.3.23.9 можно деактивировать; 0.3.23.10 не обязателен.
Требования исходного ядра сохранены: PHP 8.3+, WordPress 6.9+.
На живой сайт обновление не устанавливалось.
