CKM — Оплата в стандартном шаблоне WordPress, 0.3.23.10

1. Установить обновление CKM Payment Page Hotfix с заменой предыдущей версии.
2. Установить обновление CKM Quiz Pro с заменой предыдущей версии.
3. Открыть /ckm-payment/; при наличии кеша очистить его.

Страница создаётся/обновляется автоматически: заголовок «CKM Quiz Pro — Оплата»,
содержимое [ckm_quiz_checkout], шаблон default. Header/footer выводит тема.
Исходные title/content/template существующей страницы сохраняются в метаполе
_ckm_checkout_before_native. Другие страницы не переписываются.

Три карточки: Классический квиз 990 ₽, Битва знатоков 1990 ₽,
Интеллектуальный батл 2490 ₽. Доступ 30 дней. Выбор через параметр game.
CSS только внутри .ckm-checkout, без принудительных цветов/шрифтов/фона.

Переход к шлюзу использует существующий фильтр ckm_create_game_payment_url.
В приложенных исходниках реализации этого фильтра нет. Если внешний платёжный
модуль его не предоставляет, выводится «Платёжный шлюз не подключён».
Гость сначала входит в учётную запись и возвращается к выбранной игре.
Эта сборка не создаёт интеграцию с ЮKassa и не выдаёт доступ по нажатию кнопки.

Требования основного плагина сохранены: PHP 8.3+, WordPress 6.9+.
Проверка на живом сайте и реальный платёж в рамках сборки не выполнялись.
