CKM Quiz Pro 0.3.23.13 — несколько игр в заказе

Обновить CKM Quiz Pro с заменой предыдущей версии.
«Добавить другие игры» сохраняет выбранные игры и открывает остальные карточки.
«Добавить» включает игру в заказ. «Убрать из заказа» пересчитывает итог.
Игра может присутствовать один раз. Выбор сохраняется при обновлении страницы
в параметре games; старые ссылки с game поддерживаются.

Суммы (RUB, доступ на каждую игру 30 дней):
Классический квиз + Битва знатоков: 2980 ₽.
Классический квиз + Интеллектуальный батл: 3480 ₽.
Битва знатоков + Интеллектуальный батл: 4480 ₽.
Все три игры: 5470 ₽.

Сумма рассчитывается PHP по каталогу, неизвестные ключи отклоняются,
дубли удаляются. AJAX передаёт только ключи игр и nonce, не цену.
До действующего оплаченного доступа боковая панель и запуск скрыты.

ПЛАТЁЖНАЯ ИНТЕГРАЦИЯ
Для одной игры сохранён фильтр ckm_create_game_payment_url.
Для нескольких используется новый фильтр ckm_create_cart_payment_url:
аргументы callback: URL (изначально пустой), cart, user_id; accepted_args=3.
cart: format_keys[], items[], total_minor (целые копейки), currency=RUB.
item: format_key, title, amount_minor, quantity=1, days=30.
Обработчик должен создать единый платёж на total_minor, сохранить состав
заказа на сервере и вернуть URL платежа либо WP_Error.
После проверенного подтверждения платежа внешний модуль должен выдать доступ
каждому format_key из сохранённого заказа через существующий payment-success
контракт. Не брать состав и сумму из параметров страницы возврата.

Реализации шлюза в предоставленных архивах нет. Без нового обработчика общий
платёж не создаётся, выводится «Оплата нескольких игр пока не подключена».
Fallback к оплате только первой игры намеренно отсутствует.

Проверено: синтаксис JS, передача полного списка без цены, обработка ошибок,
проверки структуры PHP-кода и целостность архива.
PHP runtime и живой WordPress недоступны: PHP и реальное списание не проверены.
