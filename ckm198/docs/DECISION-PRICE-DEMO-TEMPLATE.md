# Управленческая игра "Ваш выбор" — демо-шаблон

Добавлен опубликованный шаблон `Демо: Управленческая игра "Ваш выбор"` (`demo-solution-price`) в общую таблицу шаблонов CKM Quiz Pro.

Мини-версия содержит 5 коротких текстовых этапов:
1. анализ проблемы;
2. решение;
3. риски;
4. корректировка после нового обстоятельства;
5. финальное обоснование.

Формат шаблона: `solution_price`.
