# 0.3.23.76-dev.108 — CHGK Early Answer + Bonus Minute

Изменена структура раунда «Битвы знатоков»:

1. Ведущий задаёт вопрос без таймера обсуждения.
2. 5 секунд доступна кнопка «Досрочный ответ».
3. Если команда нажимает её, сразу открывается окно окончательного ответа на 20 секунд.
4. Если команда не отвечает досрочно, начинается обычное обсуждение.
5. После обсуждения окно окончательного ответа также длится 20 секунд.
6. Принятый досрочный ответ даёт команде одну доступную кнопку «Дополнительная минута».
7. Видимые статусы приведены к русским формулировкам.
