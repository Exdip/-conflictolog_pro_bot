CKM Quiz Pro 0.3.23.134-dev.166-PERSUADE-ME-CONTENT-EDITOR

Следующий этап конструктора «Переговори другого».

Добавлено:
- отдельный редактор содержания всех 4 раундов в кабинете организатора;
- такой же редактор в техническом WordPress-редакторе;
- раунд 1: 3 ситуации, задача переговорщика, закрытая роль оппонента, инструкция наблюдателя;
- раунд 2: общая ситуация, инструкция собеседникам, по 3 скрытые задачи каждой команде;
- раунд 3: по 3 неудобных вопроса каждой команде + инструкции участникам;
- раунд 4: 3 досье, по 5 контрольных фактов, инструкция допустимого искажения, инструкция проверяющим;
- пользовательское содержание хранится в format_settings_json.persuadeMeContent и попадает в неизменяемый snapshot комнаты;
- секретные роли/задачи/досье не публикуются в общем state и раскрываются только соответствующим участникам по существующим правилам;
- для пользовательской игры сохраняется технический active-question contract marker, чтобы общий room engine не отклонял четырёхраундовую механику как шаблон без вопросов;
- таймеры «Переговори другого» в конструкторе показаны как фиксированные, чтобы UI не обещал несуществующую настройку.

Совместимость:
- старые демо и комнаты без persuadeMeContent продолжают использовать встроенный стандартный набор;
- уже созданная комната хранит собственный snapshot содержания и не меняется после последующего редактирования шаблона;
- общий entitlement «Переговорные поединки» и runtime communicate сохранены.

Проверки:
- PHP lint всех PHP-файлов;
- существующие dialogue/hidden/hard/story/E2E/final/AI-host tests;
- новый persuade-me-content-editor-test: custom content round-trip + защита закрытой роли;
- builder coverage test обновлён для dedicated editor.
