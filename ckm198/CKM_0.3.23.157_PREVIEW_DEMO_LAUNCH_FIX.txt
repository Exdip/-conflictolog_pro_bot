Версия: 0.3.23.157-dev.189-PREVIEW-DEMO-LAUNCH-FIX
База: 0.3.23.156-dev.188-INTEGRATED-REVIEW-RECOVERY.

Исправление BUG-01: в режиме просмотра кабинета WordPress-администратор теперь может запускать только встроенные демо-игры через кнопку «Создать ссылки команд».

Безопасность:
- общий запрет изменений в preview-режиме сохранён;
- разрешён только POST ckm_qp_front_create_game;
- только для WordPress-администратора manage_options;
- только для белого списка встроенных demo slug;
- запуск создаётся как test_mode=1, поэтому не требует оплаченного доступа организатора;
- редактирование, конструктор, история, удаление, оплата и прочие POST-действия в preview по-прежнему запрещены.

В белый список включены: классический квиз, Битва знатоков, Интеллектуальный батл, Управленческая игра "Ваш выбор", три переговорных поединка и «Переговори другого».

Цель живого теста: открыть «Демо: Переговори другого», нажать «Создать ссылки команд» и получить ссылки ведущего/табло/команд A-B-C без сообщения «Режим просмотра не позволяет изменять данные».
