CKM Quiz Pro 0.3.23.164-dev.196-PERSUADE-HIDDEN-MESSAGE-LIMIT

Изменения:
- Раунд 2 «Скрытая задача» по умолчанию ограничен 7 репликами на испытание без возврата общего таймера.
- Активная команда может отправить до 3 реплик; каждый из двух собеседников — до 2.
- После достижения общего лимита диалог автоматически закрывается и передаётся на ИИ-оценку. Ведущий по-прежнему может завершить диалог раньше.
- В интерфейсе показываются общий счётчик реплик и индивидуальная квота команды. После исчерпания квоты поле ввода скрывается.
- В конструкторе добавлено поле «Максимум реплик» для раунда «Скрытая задача» (3–7, по умолчанию 7).
- Старые уже созданные игры получают безопасное значение по умолчанию 7, если настройка отсутствует в snapshot.
- Раунд 1 «Удержи цель», раунд 3 и финал не менялись.
