0.3.23.78-dev.110-CHGK-HOST-COMMAND-FIX

Исправлена команда панели ведущего для статической страницы /ckm/quiz-host.html.

Причина: современная панель отправляла поле action, а серверный обработчик ожидал command.
В результате кнопка «Задать вопрос» могла выглядеть активной, но сервер получал пустую команду и не открывал вопрос.

Что сделано:
- фронтенд отправляет command и сохраняет action только для обратной совместимости;
- сервер принимает command, а при его отсутствии использует action;
- ошибка стала безопасной для старых и новых сборок фронтенда.
