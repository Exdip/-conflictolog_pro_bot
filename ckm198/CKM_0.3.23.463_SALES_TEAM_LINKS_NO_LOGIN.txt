CKM Quiz Pro 0.3.23.463-dev.495-SALES-TEAM-LINKS-NO-LOGIN

Эффективный продажник — соревнование без логинов/email команд.

Изменения:
- организатор указывает только количество и названия 2–6 команд;
- система автоматически создаёт техническую командную учётную запись с неизвестным случайным паролем;
- для каждой команды генерируется отдельная подписанная ссылка;
- переход по ссылке автоматически открывает командную попытку, ручной вход не нужен;
- ссылки видит организатор на странице соревнования; есть кнопка «Копировать»;
- подсказки ИИ-тренера в соревновании по-прежнему отключены;
- рейтинг по-прежнему скрыт до завершения всех команд;
- новых таблиц БД не требуется.

Безопасность:
- ссылка является ключом доступа команды;
- подпись HMAC привязана к assignment_id, team-user и секрету;
- ссылка работает только для активного team_shared/exam соревнования;
- технический аккаунт имеет роль subscriber и случайный пароль.
