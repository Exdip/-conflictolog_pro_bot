CKM Quiz Pro 0.3.23.220-dev.252 — READY GAME SNAPSHOT ARCHITECTURE

1. Готовая игра из администраторского каталога теперь является исходным шаблоном.
2. После первой оплаты создаётся приватная копия квиза для площадки/организатора.
3. Копируются текущая редакция квиза, раунды, вопросы и настройки формата.
4. В ckm_quiz_ready_instances сохраняются источник, исходная редакция, snapshot quiz_id, hash и снимок карточки каталога.
5. Повторная оплата/продление использует ту же копию.
6. Изменения администратором исходного шаблона не меняют ранее купленные игры.
7. Покупки, сделанные до этого обновления, получают snapshot лениво при открытии каталога/Моих игр.
8. «Мои игры» больше не показывает администраторский исходник готовой игры; показывается приватная копия.
9. Запуск проверяет entitlement конкретной готовой игры, а не только базовый format_key.
10. Сессии по-прежнему фиксируют quiz_revision и snapshot настроек формата для истории.
