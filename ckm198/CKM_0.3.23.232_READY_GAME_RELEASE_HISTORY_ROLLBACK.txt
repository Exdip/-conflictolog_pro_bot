CKM Quiz Pro 0.3.23.232-dev.264 — READY GAME RELEASE HISTORY + ROLLBACK

- Для готовых игр добавлена отдельная append-only история коммерческих релизов R1, R2, R3...
- Каждая публикация фиксирует каталоговую редакцию и неизменяемый release quiz.
- В админке появился экран «Опубликованные релизы».
- Администратор может вернуть любой ранее опубликованный стабильный релиз в каталог.
- Откат создаёт новый release event и не переписывает историю.
- Рабочая редакция при откате не меняется.
- Уже купленные snapshot-копии организаторов при откате не меняются; новый релиз получают только новые покупки.
- Скрытая игра после отката остаётся скрытой.
- Для существующих стабильных релизов добавлен миграционный seed в новую таблицу истории.
