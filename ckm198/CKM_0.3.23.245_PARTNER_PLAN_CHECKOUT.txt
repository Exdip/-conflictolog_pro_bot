CKM Quiz Pro 0.3.23.246-dev.278-GAME-TITLE-RENAMES

Автоматическая оплата партнёрского режима через YooKassa владельца ЦКМ.

- Start / Business / Pro оплачиваются владельцем tenant-площадки через центральную YooKassa ЦКМ.
- После payment.succeeded платёж повторно проверяется через API YooKassa и партнёрский режим активируется автоматически на 30 дней.
- Повторный webhook/return не продлевает подписку второй раз: используется last_payment_ref + GET_LOCK.
- Цена и лимит фиксируются в заказе в момент начала оплаты.
- В админке добавлены центральные Shop ID / Secret key / test-live / НДС / webhook URL / проверка соединения.
- Secret key хранится зашифрованным AES-256-GCM.
- При включенной фискализации отправляется receipt с payment_subject=service.
- Для HTTP Basic Auth webhook настраивается в кабинете YooKassa вручную.
- Партнёрская YooKassa для платежей клиентов остаётся отдельной и не смешивается с центральной кассой ЦКМ.
- Добавлена таблица последних оплат партнёрского режима в админке.
- Кнопка админки переименована в «Сохранить тарифы и лимиты».
