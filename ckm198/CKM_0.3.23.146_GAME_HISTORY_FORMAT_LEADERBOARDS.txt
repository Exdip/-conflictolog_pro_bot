CKM Quiz Pro 0.3.23.146-dev.178-GAME-HISTORY-FORMAT-LEADERBOARDS

- Добавлен накопительный блок «Статистика игровых форматов» в истории игр.
- Для каждого формата показываются реальные запуски, завершённые игры, среднее число команд, средняя длительность и дата последней игры.
- Тестовые запуски исключены из статистики.
- Средняя длительность считается только по завершённым играм с корректными временными метками; технические сессии свыше 7 суток не искажают среднее.
- Игровой runtime, схема MySQL и расчёт результатов не изменены.


Этап 178: добавлен отдельный сравнительный блок результатов команд внутри каждого игрового формата. Тестовые и незавершённые игры исключены; первые места считаются только при 2+ командах.
