CKM Quiz Pro 0.3.23.223-dev.255 — MY GAMES UNIFIED LIBRARY

- «Мои игры» разделены на три независимых блока: Базовые игры, Готовые игры, Собственные игры.
- Базовые игры показываются только после факта покупки и сохраняют статус доступа/продления.
- Готовые игры показывают приватную snapshot-копию покупателя и остаются видимыми после окончания доступа.
- Собственные игры остаются видимыми после окончания доступа; для нового запуска требуется любой активный платный доступ.
- Организатор не получает кнопку редактирования сохранённой игры. Администратор сохраняет право редактирования собственной игры.
- Вверху «Моих игр» добавлена сводка по трём типам игр.
